# Enclave Admin Panel

منصة تحكم خاصة ببوت Enclave RP — تسجيل دخول برقم سري فقط (بدون يوزرنيم)،
تحكم كامل بالبوت (رسائل خاصة، إعلانات، moderation)، وسجل نشاط لكل فعل يصير.

يشتغل داخل **نفس سيرفس `welcome-bot`** على Railway (مو سيرفس منفصل) — شوف
`start-merged.sh` بجذر المستودع: يشغّل بوت الترحيب ومنصة الإدارة كعمليتين
منفصلتين بنفس الحاوية، فيستخدمون نفس `DISCORD_TOKEN` و`GUILD_ID` تلقائيًا
بدون أي إعداد إضافي. البيانات (الحسابات/الجلسات/سجل النشاط) تُخزّن بملف
SQLite على الـ Volume المرفق بسيرفس welcome-bot (بدون حاجة لقاعدة بيانات
منفصلة).

يتواصل مع ديسكورد عبر REST API مباشرة (بدون Gateway/WebSocket) — يعني ما
يحتاج يفضل متصل بشكل دائم، كل فعل (إرسال، طرد، حظر...) طلب لحظي واحد.

## المميزات

- **تسجيل دخول برقم سري فقط** — بدون يوزرنيم. حسابات الدخول تُنشأ من داخل
  المنصة نفسها، من حساب الـ Owner فقط — وتختار العضو من قائمة بحث حقيقية
  (اسم/يوزرنيم) بدل كتابة ID يدويًا، والمنصة ترسل له تلقائيًا رابط الدخول
  ورقمه السري وتحذير أمان بالخاص.
- **رسائل خاصة (DM)** — للكل، أو لأعضاء رول معيّن، أو لعضو تختاره بالبحث.
- **إعلانات** — نشر بأي قناة تختارها، بشريط تنسيق (عريض/مائل/اقتباس/مخفي...).
- **Moderation** — طرد، حظر/فك حظر (باختيار من قائمة المحظورين)، تايم أوت،
  تحذير، حذف رسائل (Purge)، قفل/فتح قناة.
- **إدارة السيرفر** — إنشاء/تعديل/حذف قنوات وكاتجوريز ورولات (بالصلاحيات
  والألوان) — يحتاج البوت صلاحية **Manage Channels** و**Manage Roles**،
  ورول البوت لازم يكون أعلى بالترتيب من أي رول يعدّله.
- **رسائل ثابتة قابلة للتعديل** — نص رسالة الترحيب والرسالة الخاصة يتغيّران
  من المنصة نفسها بدون لمس الكود.
- **سجل نشاط** — كل فعل يصير من المنصة مسجّل (مين سواه، وش سوى، وامتى).
- **PWA** — صفحة `/install` تكتشف جهازك تلقائيًا (آيفون/أندرويد/كمبيوتر)
  وتوريك خطوات التثبيت المناسبة، أو تقدر تكمل من المتصفح مباشرة بدون تثبيت.
- **لا تكشف أي معلومة تقنية** — رسائل الخطأ للمستخدم عامة دايمًا، التفاصيل
  (توكنات، أخطاء داخلية) تطلع بلوقات السيرفر بس.

## الإعداد على Railway

المنصة مدمجة بسيرفس `welcome-bot` الموجود أصلًا — ما فيه سيرفس جديد ولا قاعدة
بيانات جديدة تحتاج تسويها. اللي احتاجه فقط:

### ١. متغيرات البيئة الإضافية (على سيرفس welcome-bot نفسه)

| المتغير | القيمة |
|---|---|
| `SESSION_SECRET` | نص عشوائي طويل (٣٢+ حرف) — ولّده مرة وحطه ثابت |
| `OWNER_SETUP_PIN` | رقم سري لأول حساب Owner (٤-٣٢ رقم) |
| `OWNER_SETUP_NAME` | اسمك يظهر بالمنصة (اختياري، افتراضي "Owner") |
| `TEST_MODE_REDIRECT_USER_ID` | `1303195553068482591` أثناء التجربة — احذفه بالكامل لما تخلص |

`DISCORD_TOKEN` و`GUILD_ID` موجودين أصلًا على هذا السيرفس — المنصة تستخدمهم
تلقائيًا بدون تكرار. `SQLITE_PATH` ما يحتاج ضبط (افتراضيًا `/data/admin.db`
على نفس الـ Volume المرفق).

### ٢. الدومين الخاص (enclave-admin.tsh87.com)
- بسيرفس `welcome-bot` على Railway: **Settings** → **Networking** →
  **Custom Domain** → اكتب `enclave-admin.tsh87.com`.
- Railway بيعطيك سجل **CNAME**.
- ضيف نفس السجل بإعدادات DNS لدومين `tsh87.com` (Cloudflare).
- انتظر دقايق وRailway بيفعّل SSL تلقائيًا.

### ٣. أول تشغيل
- بعد أول Deploy، افتح الدومين وسجل دخول برقم `OWNER_SETUP_PIN`.
- من صفحة **إدارة الحسابات** سوّي حسابات إضافية لمن تبي.
- بعدها احذف/غيّر `OWNER_SETUP_PIN` — مو ضروري بعد أول تشغيل.

## وضع التجربة

طول ما `TEST_MODE_REDIRECT_USER_ID` معبّى، أي رسالة خاصة أو إعلان يطلع من
المنصة — بغض النظر عن هدفه الحقيقي (الكل / رول / عضو / قناة) — يروح لهذا
العضو فقط، وينكتب بسجل النشاط إنه كان تجربة ولمين كان المفروض يروح. صفحة
الرئيسية تعرض تنبيه واضح طول ما وضع التجربة شغّال.

**لبدء التشغيل الفعلي:** احذف متغير `TEST_MODE_REDIRECT_USER_ID` بالكامل من
Variables بـ Railway وأعد النشر (Redeploy).

## ملاحظات أمان

- الرقم السري لكل حساب مخزّن مشفّر (bcrypt) — ما فيه ولا مكان يظهر فيه نص عادي.
- الجلسات محفوظة بقاعدة البيانات وتقدر تُلغى فورًا (لو حذفت حساب، جلساته
  تنحذف تلقائيًا).
- محاولات الدخول محدودة (٨ محاولات كل ٥ دقايق لكل IP) لتقليل خطر التخمين —
  خلي الأرقام السرية طويلة بشكل معقول (٦+ أرقام).
- لو غيّرت `SESSION_SECRET` كل الجلسات المسجّلة دخول بتنقطع (لازم الكل يسجل
  دخول من جديد) — غيّره بس لو تشك في تسريب.
- صلاحية إنشاء/حذف الحسابات محصورة بحسابات Owner فقط.

## تشغيل محلي (اختياري، للتجربة بس)

```bash
cd admin-panel
npm install
cp .env.example .env   # واملأ القيم (SQLITE_PATH محليًا: أي مسار داخل المشروع)
npm start
```
