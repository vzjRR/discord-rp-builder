# Enclave Admin Panel

منصة تحكم خاصة ببوت Enclave RP — تسجيل دخول برقم سري فقط (بدون يوزرنيم)،
تحكم كامل بالبوت (رسائل خاصة، إعلانات، moderation)، وسجل نشاط لكل فعل يصير.

مشروع مستقل بذاته (زي `welcome-bot` و`logs-bot` بنفس المستودع) — يُنشر كسيرفس
منفصل على Railway، ويستخدم نفس `DISCORD_TOKEN` و`GUILD_ID`.

يتواصل مع ديسكورد عبر REST API مباشرة (بدون Gateway/WebSocket) — يعني ما
يحتاج يفضل متصل بشكل دائم، كل فعل (إرسال، طرد، حظر...) طلب لحظي واحد.

## المميزات

- **تسجيل دخول برقم سري فقط** — بدون يوزرنيم. حسابات الدخول تُنشأ من داخل
  المنصة نفسها، من حساب الـ Owner فقط.
- **رسائل خاصة (DM)** — للكل، أو لأعضاء رول معيّن، أو لعضو واحد بالـ ID.
- **إعلانات** — نشر بأي قناة تختارها.
- **Moderation** — طرد، حظر/فك حظر، تايم أوت، تحذير، حذف رسائل (Purge)،
  قفل/فتح قناة.
- **سجل نشاط** — كل فعل يصير من المنصة مسجّل (مين سواه، وش سوى، وامتى).
- **PWA** — تقدر تثبتها على الهاتف من المتصفح (Add to Home Screen) أو
  تستخدمها عادي من المتصفح بدون تثبيت.
- **لا تكشف أي معلومة تقنية** — رسائل الخطأ للمستخدم عامة دايمًا، التفاصيل
  (توكنات، أخطاء داخلية) تطلع بلوقات السيرفر بس.

## الإعداد على Railway (خطوات يدوية — مرة وحدة بس)

المنصة كودها جاهز ومدفوع للمستودع، بس تشغيلها فعليًا يحتاج منك تسوي هالخطوات
من لوحة Railway (ما أقدر أوصل لحسابك بـ Railway من هنا):

### ١. سيرفس جديد
- بمشروع Railway تبعك: **New** → **GitHub Repo** → اختر نفس المستودع
  (`discord-rp-builder`).
- بإعدادات السيرفس الجديد (Settings): اضبط **Root Directory** = `admin-panel`.
- Railway بيلقط `railway.json` تلقائيًا (build: `npm install`, start: `npm start`).

### ٢. قاعدة البيانات
- بنفس المشروع: **New** → **Database** → **PostgreSQL**.
- Railway بيضيف تلقائيًا متغير `DATABASE_URL` مشترك تقدر تربطه لسيرفس المنصة
  من تبويب **Variables** (Add Variable Reference → اختر متغير `DATABASE_URL`
  من سيرفس الـ Postgres).

### ٣. متغيرات البيئة (Variables بسيرفس المنصة)

| المتغير | القيمة |
|---|---|
| `DISCORD_TOKEN` | نفس توكن البوت المستخدم بـ welcome-bot |
| `GUILD_ID` | نفس ID السيرفر |
| `DATABASE_URL` | Reference لمتغير الـ Postgres (خطوة ٢) |
| `SESSION_SECRET` | نص عشوائي طويل (٣٢+ حرف) — ولّده مرة وحطه ثابت |
| `OWNER_SETUP_PIN` | رقم سري تختاره لأول حساب Owner (٤-٣٢ رقم) |
| `OWNER_SETUP_NAME` | اسمك يظهر بالمنصة (اختياري، افتراضي "Owner") |
| `TEST_MODE_REDIRECT_USER_ID` | `1303195553068482591` أثناء التجربة — احذفه بالكامل لما تخلص |

### ٤. أول تشغيل
- بعد أول Deploy ناجح، افتح رابط السيرفس (Railway يعطيك رابط `*.up.railway.app`
  تلقائيًا) وسجل دخول برقم `OWNER_SETUP_PIN`.
- من صفحة **إدارة الحسابات** سوّي حسابات إضافية لمن تبي (تحدد اسمهم ورقمهم
  السري بنفسك — هم ما يقدرون يسوون حسابات لأنفسهم).
- بعدها احذف متغير `OWNER_SETUP_PIN` من Railway (أو غيّره) — مش ضروري بعد
  أول تشغيل، وخليه يبقى موجود بس لو تبي تعيد تعيين حساب Owner لاحقًا.

### ٥. الدومين الخاص (enclave-admin.tsh87.com)
- بسيرفس المنصة على Railway: **Settings** → **Networking** → **Custom Domain**
  → اكتب `enclave-admin.tsh87.com`.
- Railway بيعطيك سجل **CNAME** (شكله عادة `xxxx.up.railway.app`).
- روح لإعدادات DNS لدومينك `tsh87.com` (عند الشركة اللي مسجّل عندها الدومين)
  وضيف سجل:
  - النوع: `CNAME`
  - الاسم/Host: `enclave-admin`
  - القيمة: اللي عطاك ياها Railway
- انتظر شوي (عادة دقايق، أحيانًا لين ساعة) وRailway بيفعّل SSL تلقائيًا.

## وضع التجربة

طول ما `TEST_MODE_REDIRECT_USER_ID` معبّى، أي رسالة خاصة أو إعلان يطلع من
المنصة — بغض النظر عن هدفه الحقيقي (الكل / رول / عضو / قناة) — يروح لهذا
العضو فقط، وينكتب بسجل النشاط إنه كان تجربة ولمين كان المفروض يروح. صفحة
الرئيسية تعرض تنبيه واضح طول ما وضع التجربة شغّال.

**لبدء التشغيل الفعلي:** احذف متغير `TEST_MODE_REDIRECT_USER_ID` بالكامل من
Variables بـ Railway وأعد النشر (Redeploy).

## ملاحظات أمان

- الرقم السري لكل حساب مخزّن مشفّر (bcrypt) — ما فيه ولا مكان يظهر فيه نص عادي.
- الجلسات محفوظة بقاعدة البيانات وتقدر تُلغى فورًا (لو حذفت حساب، جلساته
  تنحذف تلقائيًا).
- محاولات الدخول محدودة (٨ محاولات كل ٥ دقايق لكل IP) لتقليل خطر التخمين —
  خلي الأرقام السرية طويلة بشكل معقول (٦+ أرقام).
- لو غيّرت `SESSION_SECRET` كل الجلسات المسجّلة دخول بتنقطع (لازم الكل يسجل
  دخول من جديد) — غيّره بس لو تشك في تسريب.
- صلاحية إنشاء/حذف الحسابات محصورة بحسابات Owner فقط.

## تشغيل محلي (اختياري، للتجربة بس)

```bash
cd admin-panel
npm install
cp .env.example .env   # واملأ القيم (يحتاج Postgres محلي أو من Railway)
npm start
```
