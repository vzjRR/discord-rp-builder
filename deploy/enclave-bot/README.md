# بوت سيرفر Enclave

يرحّب بالأعضاء الجدد بصورة تحمل أسماءهم، ويسجّل الانضمام والمغادرة وعدّاد
رسائل يومي لكل عضو — وهي مصدر صفحة «حالة السيرفر» في المنصة.

| | |
|---|---|
| المجلد | `welcome-bot/` |
| الخدمة | `enclave-bot` |
| الأسرار | `/etc/enclave/enclave-bot.env` |
| البيانات | `/data/server-events.db` |

## النشر

الصق `cloud-init.yaml` عند إنشاء الخادم، ثم من Cloud Shell:

```bash
sudo -i
nano /etc/enclave/enclave-bot.env
systemctl enable --now enclave-bot
journalctl -u enclave-bot -f
```

## ما يحتاجه من ديسكورد

- **Server Members Intent** مفعّلة في Developer Portal ← Bot، وإلا لم يصله
  حدث انضمام عضو أصلًا.
- صلاحية **Manage Server** في السيرفر، ليقرأ قائمة الدعوات فيعرف من دعا
  العضو الجديد. بدونها يعمل الترحيب، لكن كل عضو يظهر وكأنه دخل عبر رابط
  السيرفر العام.
- `GuildMessages` لعدّ الرسائل — غير مميّزة ولا تحتاج تفعيلًا. ولا يُقرأ
  نص أي رسالة ولا يُخزَّن، العدد فقط.

## الخطوط

`FONTCONFIG_PATH` في وحدة الخدمة يشير إلى الخطوط المدمجة. ومجلدها مفتوح
للكتابة في الوحدة لأن `fonts.conf` يضع الكاش بداخله — وبدون ذلك تتدهور
الأسماء العربية في الصورة.
