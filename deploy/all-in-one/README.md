# كل شيء على خادم واحد

ينشر خدمتين معًا: منصة الإدارة، وبوت سيرفر Enclave. **هذا هو الوضع
الموصى به.**

> بوتات سيرفر LSPD (ترحيب، لوقات، تذاكر) لها مستودع ونشرة منفصلان تمامًا
> الآن: [`vzjRR/ENCLAVE-LSPD`](https://github.com/vzjRR/ENCLAVE-LSPD) —
> يمكن نشرها على نفس هذا الخادم أو أي خادم آخر.

## لماذا خادم واحد

- الشريحة المجانية الواحدة تسع الاثنتين بفائض كبير: عمليتا Node خفيفتان،
  ذروتهما لحظة توليد صورة ترحيب.
- المنصة وبوت Enclave يتشاركان `/data/server-events.db` — البوت يكتبه
  والمنصة تقرأه. اجتماعهما يجعل صفحة «حالة السيرفر» كاملة دون ترتيب
  إضافي؛ وافتراقهما يفقدها «آخر المغادرين» و«الأكثر تفاعلًا».
- خادم واحد يعني تحديثًا واحدًا ونسخة احتياطية واحدة وسجلات في مكان واحد.

الجمع في خادم لا يعني الدمج في خدمة: لكل واحدة ملف أسرار مستقل ووحدة
تشغيل مستقلة، فتُشغَّل وتُوقَف وتُحدَّث كلٌّ على حدة، وسقوط إحداها لا
يُسقط غيرها.

إن أردت لاحقًا فصل خدمة على خادمها، فمجلدها في `deploy/` يحوي
`cloud-init.yaml` مستقلًا لذلك.

## الخطوات

### ١) أنشئ الخادم

من لوحة Oracle Cloud: **Compute ← Instances ← Create instance**

| الخيار | القيمة |
|---|---|
| Image | Ubuntu 24.04 |
| Shape | `VM.Standard.A1.Flex` — ٢ معالج و١٢ غيغابايت |

ضمن «Always Free» دائمًا. المتاح مجانًا ٤ معالجات و٢٤ غيغابايت، فارفعها
إن شئت؛ وما فوقها يُحاسَب. ولا تختر `E2.1.Micro` ذات الغيغابايت الواحد —
تضيق بتوليد الصور.

**Advanced options ← Management ← Paste cloud-init script**، والصق
[`cloud-init.yaml`](./cloud-init.yaml) كاملًا.

احفظ مفتاح SSH الذي تعرضه الصفحة؛ فقدانه يعني فقدان الطريق الوحيد إلى
الخادم إن تعطّل شيء.

اضغط **Create**. يهيّئ الخادم نفسه خلال خمس إلى عشر دقائق.

### ٢) أنشئ نفق Cloudflare

المنصة وحدها تحتاج وصولًا من الخارج، ويصلها عبر نفق يفتحه الخادم اتصالًا
**صادرًا**. فلا منفذ وارد، ولا عنوان يُكتشف، ولا شهادة تُدار على الأصل —
**ولا رابط استضافة خام يمكن أن يتسرّب**.

من لوحة Cloudflare: **Zero Trust ← Networks ← Tunnels ← Create a tunnel**

1. اختر **Cloudflared**، وسمِّ النفق `enclave`.
2. انسخ رمز التثبيت (يبدأ بـ `eyJ...`).
3. أضف Public hostname:
   - **Subdomain** `enclave-admin` — **Domain** `tsh87.com`
   - **Service** `HTTP` ← `localhost:3000`

Cloudflare ينشئ سجلّ الـ DNS تلقائيًا. بعدها احذف أي سجلّ قديم لهذا
الاسم، والـ Worker السابق — لم تعد له وظيفة.

### ٣) أكمل من المتصفح

من لوحة Oracle: **Cloud Shell** (أيقونة الطرفية أعلى الصفحة) — تعمل داخل
المتصفح ولا تحتاج برنامجًا على الآيباد.

```bash
ssh ubuntu@<عنوان-الخادم>
sudo -i
```

**املأ الأسرار — ملفان منفصلان:**

```bash
nano /etc/enclave/panel.env         # المنصة
nano /etc/enclave/enclave-bot.env   # بوت Enclave
```

> `SESSION_SECRET` في `panel.env` يجب أن يبقى كما كان على الاستضافة
> السابقة. تغييره يُبطل جلسات كل المسؤولين فيُطالَبون بالدخول من جديد.
> وإن لم تعرفه فولّد غيره واقبل بذلك — لا ضرر عدا إعادة الدخول.

**استعد بيانات المنصة** (ارفع ملف النسخة عبر زرّ الرفع في Cloud Shell):

```bash
node /opt/enclave/admin-panel/scripts/restore-backup.js ~/enclave-backup.json /data
chown -R enclave:enclave /data
```

**النفق والتشغيل:**

```bash
cloudflared service install <رمز-النفق>
systemctl enable --now enclave-panel enclave-bot
systemctl status enclave-panel enclave-bot --no-pager
```

## ٤) تحقّق قبل حذف القديم

```bash
journalctl -u enclave-panel -n 30 --no-pager
journalctl -u enclave-bot -n 30 --no-pager
```

ثم من المتصفح:

- [ ] `https://enclave-admin.tsh87.com` تفتح صفحة الدخول
- [ ] رقمك السري القديم يعمل (دليل نجاح الاستعادة)
- [ ] «إدارة الحسابات» تعرض المسؤولين الثمانية بصلاحياتهم
- [ ] «سجل النشاط» يعرض القيود القديمة
- [ ] «حالة السيرفر» تعرض الأعضاء
- [ ] عضو جديد يدخل Enclave فتصله صورة ترحيب

**عند اكتمالها كلها فقط** احذف مشاريع الاستضافة القديمة.

بوتات LSPD منفصلة تمامًا — انشرها وتحقّق منها عبر
[`vzjRR/ENCLAVE-LSPD`](https://github.com/vzjRR/ENCLAVE-LSPD).

## التشغيل اليومي

```bash
# تحديث الكود لكل الخدمات
cd /opt/enclave && git pull
systemctl restart enclave-panel enclave-bot

# خدمة واحدة فقط
systemctl restart enclave-bot

# المتابعة
journalctl -u enclave-panel -f
```

**نسخة احتياطية** — من المنصة: «إدارة الحسابات» ← تنزيل النسخة
الاحتياطية. اجعلها عادة شهرية واحفظها خارج الخادم؛ فنسخة تعيش على الجهاز
الذي تحميه ليست نسخة احتياطية.
