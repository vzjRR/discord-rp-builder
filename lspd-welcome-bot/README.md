# LSPD Welcome Bot

بوت ترحيب سيرفر LSPD (Enclave RP Police Department) — يرسل رسالة ترحيب مع صورة
مولّدة تلقائيًا لكل عضو جديد، ويعطيه رول تلقائي، ويرسل له رسالة خاصة.

مشروع مستقل بذاته زي `welcome-bot` و`logs-bot` بنفس المستودع — يُنشر كسيرفس
منفصل على Railway بتوكن وGUILD_ID خاصين بسيرفر LSPD.

## أصل هذا المجلد

الكود كان منشور على Railway برفع مباشر من كمبيوتر (`railway up`) بدون ربط
بمستودع GitHub — يعني أي تعديل كان يحتاج نفس الجهاز اللي رفعه. تم استرجاع
الكود من الحاوية الشغّالة ورفعه هنا عشان يصير قابل للتعديل والنشر من أي مكان.

## متغيرات البيئة (Railway → Variables)

| المتغير | القيمة |
|---|---|
| `DISCORD_TOKEN` | توكن بوت LSPD |
| `GUILD_ID` | ID سيرفر LSPD |

## ملفات assets

- `assets/welcome_template.png` — بانر الترحيب (1536×688)
- `assets/font-bold.ttf` — الخط المستخدم لكتابة اسم العضو على الصورة

لو أي ملف منهم ناقص، توليد الصورة بيفشل والبوت بيرسل النص فقط (بدون ما
يتعطّل) — تشوف تحذير `⚠️ فشل توليد صورة الترحيب` باللوقات.

## التشغيل محليًا

```bash
cd lspd-welcome-bot
npm install
cp .env.example .env   # واملأ القيم
npm start
```
