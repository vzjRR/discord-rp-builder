# 🍦 enclave_icecream — مطعم مثلجات لـ FiveM

مورد وظيفة كامل لمحل مثلجات في GTA V / FiveM: تصنيع حقيقي بمكونات، طلبات زبائن،
كاشير وفوترة، توريد مواد، عربة مثلجات متنقلة، حساب شركة ومنيو بوس، ورواتب —
كل ذلك مع تحقق سيرفري كامل ولوقات ديسكورد.

**يشتغل على:** Qbox (`qbx_core`) • QBCore (`qb-core`) • ESX (`es_extended`) • بلا فريمويرك (standalone)

## 1) ما الذي يقدّمه المورد؟

| الميزة | الشرح |
|---|---|
| **وظيفة بخمس رتب** | متدرب ← موزّع ← صانع ← مساعد مدير ← مالك، كل رتبة لها صلاحيات مختلفة |
| **تسجيل دوام** | نقطة دوام مع بلب؛ خارج الدوام لا تصنيع ولا فوترة ولا فريزر |
| **4 محطات عمل** | ماكينة سوفت سيرف • طاولة تحضير • خلاط • فرن وافل |
| **16 وصفة** | بمكونات حقيقية، أوقات مختلفة، أنيميشن، واختبار مهارة للوصفات الصعبة |
| **طلبات زبائن NPC** | يظهر زبون بطلب محدد ووقت صلاحية؛ سلّمه مباشرة للزبون أو من قائمة الكاشير |
| **فوترة اللاعبين** | كاشير يفوتر لاعبًا قريبًا؛ اللاعب يوافق أو يرفض |
| **توريد المواد** | شراء بالجملة من المورّد + جولة توريد بشاحنة حقيقية تُخرج لك مقابل أجر إضافي |
| **عربة مثلجات متنقلة** | بيع في 7 نقاط ساخنة على الخريطة بسعر أعلى ×1.4 |
| **حساب شركة** | رصيد مستقل محفوظ بقاعدة البيانات، إيداع وسحب من منيو البوس |
| **منيو بوس** | توظيف، فصل، تغيير رتبة، إحصائيات، إدارة الرصيد |
| **رواتب دورية** | تُخصم من حساب الشركة وتُصرف للموظفين على الدوام |
| **نظام الذوبان** ❄️ | المثلجات تفقد قيمتها مع الوقت خارج الفريزر — ميزة خاصة بمحل المثلجات |
| **لوقات ديسكورد** | كل عملية مالية وإدارية ومحاولة غش تصل قناتك |
| **لغتان** | عربي (افتراضي) وإنجليزي |

## 2) المتطلبات

### إلزامي
| المورد | لماذا | الرابط |
|---|---|---|
| **ox_lib** | القوائم، شريط التقدم، الإشعارات، الترجمة، الـ callbacks | https://github.com/overextended/ox_lib |

### موصى به بشدة
| المورد | لماذا |
|---|---|
| **ox_inventory** | العناصر والفريزر ونظام الذوبان (metadata). بدونه تشتغل الميزات الأساسية لكن الفريزر والذوبان لا |
| **ox_target** | مناطق التفاعل. البديل `qb-target` مدعوم |
| **oxmysql** | حفظ رصيد الشركة والإحصائيات. بدونه كل شيء يضيع عند إعادة التشغيل |

### اختياري
- فريمويرك: `qbx_core` أو `qb-core` أو `es_extended` — بدونهم يشتغل standalone (بلا فلوس ولا حقيبة)
- `qb-vehiclekeys` / `qbx_vehiclekeys` — مفاتيح عربة المثلجات تلقائيًا

> المورد **يكتشف** كل ما سبق تلقائيًا عند التشغيل. ما تحتاج تضبط شيء إلا لو الاكتشاف فشل.

## 3) التركيب — من الألف للياء

### الخطوة 1: انسخ المجلد
انسخ مجلد `enclave_icecream` إلى مجلد الموارد عندك:
```
resources/[jobs]/enclave_icecream/
```
> المهم أن يكون اسم المجلد **`enclave_icecream`** بالضبط — الـ exports وستاشات الفريزر تعتمد عليه.

### الخطوة 2: أضف العناصر
افتح `config/items.lua` — هو **مرجعي فقط ولا يُحمّل**. انسخ منه القسم المناسب لك:

**لو تستخدم ox_inventory:**
انسخ محتوى القسم 1 إلى `ox_inventory/data/items.lua` **داخل** الجدول الموجود:
```lua
return {
    -- ... العناصر الموجودة عندك
    -- 👇 الصق هنا
    ['ic_milk'] = { label = 'حليب', weight = 500, stack = true, close = false },
    -- ... إلخ
}
```

**لو تستخدم qb-core:** انسخ القسم 2 إلى `qb-core/shared/items.lua`
**لو تستخدم ESX:** نفّذ استعلام القسم 3 على قاعدة بياناتك

### الخطوة 3: أضف الوظيفة
انسخ تعريف الوظيفة من **القسم 4** في `config/items.lua`:

- **Qbox/QBCore** → `qbx_core/shared/jobs.lua` أو `qb-core/shared/jobs.lua`
- **ESX** → نفّذ استعلامات `jobs` و `job_grades`
- **standalone** → تخطَّ هذه الخطوة، المورد يدير الوظائف بنفسه

### الخطوة 4: قاعدة البيانات
المورد **ينشئ الجداول تلقائيًا** عند أول تشغيل. لو ظهر تحذير `فشل إنشاء الجداول`
(بسبب صلاحيات ناقصة)، نفّذ `sql/install.sql` يدويًا.

### الخطوة 5: أضفه لـ server.cfg
⚠️ **الترتيب مهم** — `ox_lib` لازم يبدأ قبل موردنا:
```cfg
ensure oxmysql
ensure ox_lib
ensure ox_inventory
ensure ox_target
ensure qbx_core          # أو qb-core / es_extended
ensure enclave_icecream  # 👈 دائمًا بعد ox_lib
```

### الخطوة 6 (اختياري): ويبهوك ديسكورد
في `server.cfg` — **لا تضع الرابط في الكود**:
```cfg
set icecream_webhook "https://discord.com/api/webhooks/xxxxx/yyyyy"
```

### الخطوة 7: شغّل وتأكد
أعد تشغيل السيرفر، ولازم تشوف في الكونسول:
```
[enclave_icecream] جاهز — framework=qbx inventory=ox target=ox db=true branches=1
```
لو ظهرت تحذيرات إعدادات، اقرأها — كل واحدة تقول لك بالضبط وين المشكلة.

## 4) أول اختبار داخل اللعبة

```
1. اكتب:  /ic_setjob <رقمك> 4          ← يعطيك رتبة المالك (يتطلب أدمن)
2. روح للبلب 🍦 عند شاطئ فيسبوتشي
3. عند نقطة الدوام → اضغط التفاعل → "تسجيل الدوام"
4. عند المورّد → اشترِ: حليب ×20، قشطة ×20، سكر ×20، فانيليا ×10، طحين ×10
5. عند فرن الوافل → اصنع "كون وافل"
6. عند ماكينة السوفت سيرف → اصنع "كرة فانيليا"
7. عند طاولة التحضير → اصنع "كون كرة واحدة"
8. انتظر عند الكاشير — بيجيك طلب زبون خلال 45-120 ثانية
9. سلّم الطلب: تفاعل مع الزبون مباشرة، أو الكاشير → "طلبات الزبائن" → تاخذ بقشيشك 💵
10. مكتب الإدارة → شوف رصيد الشركة زاد
```

**ما ظهر طلب؟** الطلبات تحتاج **موظف واحد على الدوام على الأقل** (`Config.Orders.minEmployeesOnDuty`).
تأكد أنك مسجّل دوام فعلًا.

## 5) كيف تلعب؟ دورة العمل الكاملة

```
        ┌──────────────────────────────────────────────────┐
        │                                                  │
        ▼                                                  │
  ① المورّد ──── شراء مواد خام (من حساب الشركة) ────┐      │
        │                                            │      │
        │  أو جولة توريد بشاحنة تُخرج لك (ربح شخصي)   │      │
        │                                            ▼      │
        │                              ② محطات العمل        │
        │                          (تصنيع بمكونات + وقت)    │
        │                                            │      │
        │                                            ▼      │
        │                          ③ منتجات جاهزة (تذوب! ❄️) │
        │                                            │      │
        │                    ┌───────────────────────┼──────┴────────┐
        │                    ▼                       ▼               ▼
        │           ④ طلبات زبائن NPC        ⑤ فوترة لاعب     ⑥ عربة متنقلة
        │              (كاشير)                  (كاشير)         (×1.4 سعر)
        │                    │                       │               │
        │                    └───────────┬───────────┴───────────────┘
        │                                ▼
        │                    75% حساب الشركة + 25% بقشيش لك
        │                                │
        └────────────────────────────────┘
                    ⑦ رواتب دورية كل 30 دقيقة من حساب الشركة
```

### الرتب والصلاحيات

| الرتبة | تصنيع | كاشير | فريزر | توريد | بوس |
|---|:---:|:---:|:---:|:---:|:---:|
| 0 — متدرب | ✅ | ❌ | ✅ | ❌ | ❌ |
| 1 — موزّع | ✅ | ✅ | ✅ | ❌ | ❌ |
| 2 — صانع مثلجات | ✅ | ✅ | ✅ | ✅ | ❌ |
| 3 — مساعد مدير | ✅ | ✅ | ✅ | ✅ | ❌ |
| 4 — المالك | ✅ | ✅ | ✅ | ✅ | ✅ |

### نظام الذوبان ❄️
المنتجات القابلة للذوبان تحمل ختم وقت الصنع:
- **أول 15 دقيقة** → قيمة كاملة 100%
- **بعدها** → القيمة تنزل تدريجيًا حتى 35%
- **بعد 45 دقيقة** → غير صالح للبيع أو الأكل نهائيًا

عند البيع، المورد يسحب **الأطزج أولًا** تلقائيًا. حطّ منتجاتك في **الفريزر** لو ما بتبيعها فورًا.
كل هذه الأرقام في `Config.Melting`.

## 6) تغيير المواقع لمحلك أنت

المواقع الافتراضية عند **شاطئ فيسبوتشي** (`-1223.5, -1576.9, 4.6`) — وهي مبنية
لتناسب MLO محل مثلجات في تلك المنطقة. لو محلك في مكان ثانٍ:

```
1. ادخل اللعبة كأدمن
2. قف بالضبط عند النقطة اللي تبيها (مثلاً: ماكينة السوفت سيرف)
3. اكتب:  /ic_coords
4. بينطبع لك سطر جاهز:
   vec3(-1222.90, -1576.20, 4.61)  |  vec4(...)  |  rotation = 35.0
5. افتح config/locations.lua وبدّل الإحداثيات
6. كرّر لكل نقطة: الدوام، الكاشير، الفريزر، المحطات، المكتب، المورّد،
   شاحنة التوريد (supplyVehicle.spawn)، وعربة المثلجات (truck.spawn)
7. أعد تشغيل المورد:  restart enclave_icecream
```

**لضبط أحجام المناطق بصريًا:** حط `Config.DebugZones = true` في `config/config.lua`
وبتشوف صناديق التفاعل مرسومة داخل اللعبة.

### إضافة فرع ثاني
انسخ كامل جدول الفرع في `Locations.Branches` وغيّر `id` والإحداثيات. المورد يدعم
عددًا غير محدود من الفروع، وكل فرع له **حساب شركة وإحصائيات وفريزر مستقل**.

## 7) الإعدادات المهمة

كل شيء في `config/config.lua`. أهم ما ستعدّله:

```lua
Config.Locale = 'ar'                        -- اللغة: ar أو en
Config.Job.name = 'icecream'                -- لازم يطابق اسم الوظيفة عند فريمويركك
Config.RequireDuty = true                   -- إجبار تسجيل الدوام

Config.Economy.societyShare = 0.75          -- نصيب الشركة من كل بيعة
Config.Economy.employeeTip  = 0.25          -- بقشيش الموظف (المجموع لازم = 1.0)
Config.Economy.startingBalance = 25000      -- رصيد الشركة الافتتاحي

Config.Paycheck.enabled = true              -- الرواتب الدورية
Config.Paycheck.intervalMinutes = 30

Config.Orders.spawnDelay = { min = 45, max = 120 }   -- سرعة وصول الزبائن
Config.Orders.maxPending = 5

Config.Crafting.timeMultiplier = 1.0        -- 0.5 = التصنيع أسرع بمرتين
Config.Crafting.maxBatch = 10

Config.Melting.freshMinutes = 15            -- متى تبدأ المثلجات تذوب
Config.Melting.ruinMinutes = 45             -- متى تتلف نهائيًا (0 = لا تتلف)
```

**الأسعار والوصفات** في `config/recipes.lua` — كل وصفة فيها `sellPrice` و `ingredients` و `time`.
**أسعار المواد الخام** في `Config.Supply.catalog`.

> ⚠️ لو غيّرت الوصفات أو المواد، المورد **يفحصها تلقائيًا** عند التشغيل ويحذّرك في الكونسول
> لو في مكوّن غير موجود أو محطة بلا وصفات.

راجع [`docs/CONFIG.md`](docs/CONFIG.md) لشرح كل خيار.

## 8) لوقات ديسكورد

المورد يرسل إيمبد لقناتك عند:

| الحدث | متى | يُتحكم به |
|---|---|---|
| 🍦 عملية بيع | كل بيعة | `Config.Server.logEverySale` (مطفأ افتراضيًا — كثيف) |
| 💰 إيداع/سحب | من منيو البوس | `Config.Server.logMoney` |
| 📦 شراء مواد | من المورّد | `Config.Server.logMoney` |
| 🧾 صرف رواتب | كل دورة | `Config.Server.logMoney` |
| ✅❌⬆️ توظيف/فصل/ترقية | من منيو البوس | `Config.Server.logEmployees` |
| 🚨 محاولة غش | عند فشل فحص المسافة أو معرّف مزوّر | `Config.Server.logExploits` |

**الإعداد:** ضع الرابط في `server.cfg` (الطريقة الآمنة — ما يدخل المستودع):
```cfg
set icecream_webhook "https://discord.com/api/webhooks/..."
```

البديل: `server/config.server.lua` — وهو ملف **سيرفري بحت** لا ينزل لجهاز اللاعب.
⚠️ **لا تضع الرابط في `config/config.lua`** — ذاك ملف `shared` وينزل للعملاء.

كل اللوقات تُحفظ أيضًا في جدول `icecream_logs` بقاعدة البيانات — حتى لو ما ضبطت ويبهوك.

## 9) الأمان — كيف بُني المورد ضد الغش

المشكلة الأشهر في سكربتات الوظائف: العميل يقول «صنعت منتج» أو «بعت بـ 99999» والسيرفر يصدّق.
هنا العميل **لا يرسل أي رقم مؤثّر** — فقط معرّفات، والسيرفر يقرأ كل شيء من الكونفق:

| الحماية | التنفيذ |
|---|---|
| **المعرّفات فقط** | العميل يرسل `recipeId`/`itemName`/`spotIndex`؛ السعر والمكونات والوقت تُقرأ سيرفريًا |
| **فحص المسافة** | كل عملية تتحقق أن اللاعب فعلًا واقف عند المحطة/الكاشير/المورّد |
| **فحص الوظيفة والدوام والرتبة** | في كل حدث، مو مرة واحدة عند فتح القائمة |
| **حد المعدّل** | لكل لاعب ولكل نوع عملية على حدة |
| **خصم المكونات مقدّمًا** | تُخصم قبل شريط التقدم، فما يقدر يبدأ عدة عمليات بنفس المكونات |
| **حجز التصنيع** | `finishCraft` بلا `startCraft` سابق يُرفض ويُسجَّل كمحاولة غش |
| **حذف الطلب قبل الدفع** | يمنع تسليم نفس الطلب مرتين |
| **الفوترة برضا الطرفين** | إعادة فحص المسافة والرصيد عند لحظة الدفع، لا عند الإرسال |
| **سقف الترقية** | البوس ما يقدر يصنع بوسات — `Config.Job.maxPromoteGrade` |
| **إرجاع تلقائي** | فشل تسليم عنصر بعد الدفع → الفلوس ترجع للشركة/اللاعب |
| **الأسرار خارج المشترك** | الويبهوك في `server/config.server.lua` — لا ينزل للعملاء |
| **تحقق كيان العربة** | ربط العربة يفحص النوع والموديل والمسافة — لا تقدر توسم مركبة غيرك |
| **تسجيل المحاولات** | كل فشل فحص يصل ديسكورد وقاعدة البيانات باسم اللاعب ومعرّفه |

## 11) حل المشاكل

| العَرَض | السبب والحل |
|---|---|
| المورد ما يبدأ، خطأ `ox_lib` | `ox_lib` لازم يكون `ensure` **قبل** `enclave_icecream` في server.cfg |
| ما يظهر شيء عند التفاعل | ما أنت موظف، أو ما سجّلت دوام. جرّب `/ic_setjob <id> 4` |
| «فشل إنشاء الجداول» | نفّذ `sql/install.sql` يدويًا |
| الفريزر ما يفتح | يحتاج `ox_inventory`. مع حقائب ثانية الفريزر معطّل |
| ما تجي طلبات زبائن | تحتاج موظفًا على الدوام. تأكد من `Config.Orders.minEmployeesOnDuty` |
| المناطق في مكان غلط | إحداثيات محلك مختلفة — راجع [القسم 6](#6-تغيير-المواقع-لمحلك-أنت) |
| العناصر ما تظهر بالحقيبة | ما أضفت العناصر من `config/items.lua` لملف عناصر فريمويركك |
| الرصيد يرجع 25000 بعد كل ريستارت | `oxmysql` غير مشتغل أو `Config.UseDatabase = false` |

قائمة أطول في [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).
